# Data

All loaders expect the same three-column schema:

| column | meaning |
|---|---|
| `source_id` | the recurring source (synthetic feed or flight number) |
| `pattern_description` | human-readable description of the source |
| `arrival_timestamp` | actual arrival time (UTC, ISO-8601) |

## `synthetic/` (committed, 26 files, 34,389 arrivals)

Generated by `arrivalcast data synthetic --source all` over 2023-01-01 to 2024-12-31.
Each source's random generator is seeded from `hash(source_id) + 42`, so you can regenerate
one source on its own and get byte-identical output. Run `arrivalcast data synthetic --list`
to see every generating rule.

## `bts/DL_JFK-LAX.parquet` (committed, 56 flight numbers, 6,527 arrivals)

This is the Bureau of Transportation Statistics *Airline On-Time Performance* data for Delta
flights JFK→LAX in 2023–2024. Each flight number is one source; cancelled and diverted flights
are dropped, so they show up as long gaps. Rebuild it from the monthly ZIPs with:

```bash
arrivalcast data bts --route JFK-LAX-DL --years 2023 2024 --raw-dir data/airline_flights_raw  # local ZIPs
arrivalcast data bts --route JFK-LAX-DL --years 2023 2024 --mode download                     # or fetch them
```

The raw monthly ZIPs (`airline_flights_raw/`, ~660 MB) and the wide feature dump
`synthetic_arrivals.csv` are git-ignored.
